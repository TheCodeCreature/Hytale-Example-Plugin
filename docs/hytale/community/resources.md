# Community Resources

## Summary

The Hytale modding community has created extensive resources for learning and reference. These complement the official documentation.

## Official Resources

| Resource | URL | Description |
|----------|-----|-------------|
| Hytale Website | https://hytale.com | Official game website |
| Hytale Blog | https://hytale.com/news | Patch notes, technical rundowns |
| Hytale Discord | https://discord.gg/hytale | Official community Discord |
