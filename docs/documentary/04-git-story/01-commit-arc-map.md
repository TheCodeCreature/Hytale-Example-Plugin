# Commit Arc Map

Use this file to convert raw Git history into story beats.

## Arc Template

| Arc Stage | Evidence in Repo | Documentary Angle |
|---|---|---|
| Trigger Problem | Early issue, failing behavior, or TODO comments | "Why change was necessary" |
| First Attempt | Initial implementation commits | "Hypothesis and ambition" |
| Resistance | Reverts, bug fixes, review feedback | "Reality check" |
| Refactor | Structural cleanup and design docs | "System thinking" |
| Breakthrough | Stable feature merge | "Turning point" |
| Outcome | Demo commits and verification docs | "Player impact" |

## Suggested Evidence Sources

- Feature design docs in `docs/`.
- Review files beginning with `review-`.
- Verification files beginning with `verify-`.
- PR descriptions and discussion threads.
