# Annotated Milestones Template

Record major repository moments and attach narrative meaning.

|---|---|---|---|---|

## Annotation Rule

Every milestone should answer both:

1. What changed technically?
2. Why should a user or player care?

## Optional Example Prompts

- "Initial architecture landed" -> what capability became possible?
- "Critical bug fixed" -> what friction disappeared for users?
- "Refactor completed" -> what became more reliable or scalable?
