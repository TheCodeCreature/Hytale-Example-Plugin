# Voiceover Script Template

Write in plain language for first-time viewers.

## Script Modes

Maintain both script forms so production can switch between controlled narration and live capture.

- Mode A: Direct Script Read (full sentences, read verbatim)
- Mode B: Live Recording Bullet Guide (short cue bullets, speak naturally)

## Recording Capture Standard

Use this so raw recordings are easy to ingest and sequence in the editor.

- Record one segment at a time in story order: Opening -> Problem -> Approach -> Evidence and Iteration -> How To Use -> Closing.
- Leave 2 to 3 seconds of silence before and after each take.
- Clap or verbal slate at take start: `segment + take number`.
- Keep one best take and one safety take per segment minimum.

## DaVinci Resolve Capture Naming

Apply naming and routing from [DaVinci Resolve Editorial Standard](00-davinci-resolve-editorial-standard.md).

Local rule:

- During recording, slate with segment and take number so files map directly to standard clip names.

## Script Quality Checklist

- [ ] A new viewer can follow without prior project context.
- [ ] Claims are supported by documented evidence.
- [ ] Includes explicit "how to use" explanation.
- [ ] Ends with a clear user-facing takeaway.
- [ ] Mode A and Mode B are both updated and aligned.
- [ ] Best/backup takes are identified for each segment.
- [ ] Pickup list is completed for any weak or missing lines.
