# Production Timeline Template

## Phase Overview

| Phase | Window | Intended Outcome |
|---|---|---|
| Discovery |  | Story intent and scope aligned |
| Capture Sprint A |  | Problem-state footage captured |
| Capture Sprint B |  | Solution-state footage captured |
| Rough Cut |  | Full structure assembled |
| Fine Cut |  | Pacing, clarity, and polish improved |
| Release |  | Publish and gather feedback |

## Detailed Milestones

### Discovery

- Lock logline and audience.
- Confirm evidence sources.
- Build initial shot list.

### Capture Sprint A

- Record baseline/problem footage.
- Record early workflow or concept footage.

### Capture Sprint B

- Record stable workflow and outcomes.
- Record interviews and reaction clips.

### Rough Cut

- Build sequence order.
- Add temporary narration.
- Validate evidence links.

### Fine Cut

- Tighten pacing and transitions.
- Replace temporary narration.
- Add captions and section markers.

### Release

- Publish cut.
- Capture viewer feedback.
- Log improvement opportunities.
