# Pre-Production Checklist Template

## Editorial Alignment

- [ ] Logline is current and approved.
- [ ] Audience groups are defined.
- [ ] Runtime target is defined.

## Capture Readiness

- [ ] Recording settings are confirmed.
- [ ] Demonstration environment is prepared.
- [ ] Required overlays/annotations are available.
- [ ] Backup states exist for retakes.

## Audio Readiness

- [ ] Mic levels tested.
- [ ] Room tone captured.
- [ ] Voice profile consistency verified.

## Source Material Readiness

- [ ] Relevant design docs bookmarked.
- [ ] Relevant commits/PRs identified.
- [ ] Required visual references exported.

## Optional Project-Specific Checks

- [ ] Accessibility/readability checks (UI text, caption sizing).
- [ ] Compliance/legal checks for shown assets.
