# Decision Ledger

Record every meaningful decision with evidence and impact.

| Decision ID | Date | Context | Decision | Rationale | Evidence Links | Impacted Files | Owner | Status |
|---|---|---|---|---|---|---|---|---|
| DEC-001 | YYYY-MM-DD |  |  |  |  |  |  | Proposed |

## Status Values

- Proposed
- Approved
- Rejected
- Superseded

## Evidence Rules

- Every approved decision must include at least one evidence link.
- If evidence is missing, use `vscode/askQuestions` before approval.
- If a decision is superseded, link the replacement decision ID.
